Things I've built.

Machine learning / full-stack web development

MBTI personality classification

A web-based personality classification application named MindScan, developed as an academic project at Universitas Gunadarma. It uses Support Vector Machine (SVM) and Term Frequency-Inverse Document Frequency (TF-IDF) to classify MBTI personality types from textual input.

Problem and objective

Classify MBTI personality types from text, and make the trained model usable through a web interface.

Technical approach

  • Text preprocessing and feature extraction
  • TF-IDF vectorization
  • SVM model development
  • Model evaluation with confusion matrix analysis

Implementation

The trained model is integrated into a Flask web application with an HTML, CSS, and JavaScript front end.
