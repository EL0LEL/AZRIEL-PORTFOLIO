# AZRIEL — Portfolio

Personal portfolio of AZRIEL, Informatics undergraduate at Universitas Gunadarma.
Single-page static site: plain HTML, CSS, and JavaScript. No build step.

## Run locally

Open `index.html` in a browser.

## Deploy with GitHub Pages

1. Push this repository to GitHub.
2. Open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch, then select `main` and `/ (root)`.
4. Save. The site will be available at `https://<username>.github.io/<repository>/`.

## Edit

- Contact links: the `CONTACT` object near the bottom of `index.html`.
- Photos and screenshots are embedded in `index.html` as base64 images.
